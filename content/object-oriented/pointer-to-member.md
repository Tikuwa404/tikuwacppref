# メンバへのポインタ
メンバへのポインタを使用したメンバ変数・メンバ関数へのアクセスについて説明します。

# メンバへのポインタとは
ある`static`でない`class`または`struct`のオブジェクトがあって、その`static`でないメンバ変数やメンバ関数にアクセスしたい時、メンバへのポインタを使用することができます。メンバへのポインタは、オブジェクトの中で指定のメンバがどの位置に格納されているのかを指します。簡単に言うなら、変数を用いてアクセスするメンバを変えることができます。

# メンバ変数へのポインタの宣言
`メンバ変数の型 クラス名::*変数名;`で宣言できます。`class`や`struct`からメンバ変数へのポインタを取得するには、`&クラス名::メンバ変数名`を使用します。メンバ定数にもアクセスできます。

オブジェクトのメンバ変数にアクセスするには、`オブジェクト名.*メンバ変数へのポインタ`を使用します。ポインタが保持しているオブジェクトのメンバ変数にアクセスするには、`ポインタ名->*メンバ変数へのポインタ`を使用します。
## 例
メンバ定数とメンバ変数を出力する。
### ソースコード
```cpp
#include <iostream>

struct MyStruct {
    const int kConstant = 10;
    int variable = 20;
};

int main() {
    const int MyStruct::*p_c = &MyStruct::kConstant;
    int MyStruct::*p_v = &MyStruct::variable;
    
    MyStruct my_struct;

    std::cout << my_struct.*p_c << '\n';
    std::cout << my_struct.*p_v << '\n';
}
```
### 出力結果
```plain
10
20

```

# メンバ関数へのポインタの宣言
`返り値の型 (クラス名::*変数名)(引数の型);`で宣言できます。`class`や`struct`からメンバ関数へのポインタを取得するには、`&クラス名::メンバ関数名`を使用します。

オブジェクトのメンバ関数にアクセスするには、`オブジェクト名.*メンバ関数へのポインタ`を使用します。ポインタが保持しているオブジェクトのメンバ関数にアクセスするには、`ポインタ名->*メンバ関数へのポインタ`を使用します。`.*`演算子や`->*`演算子は`()`演算子よりも優先度が低いのに注意が必要です。
## 例
メンバ関数を実行し、結果を出力する。
### ソースコード
```cpp
#include <iostream>

struct MyStruct {
    int func() {
        return 30;
    }
};

int main() {
    int (MyStruct::*p_f)() = &MyStruct::func;

    MyStruct my_struct;

    std::cout << (my_struct.*p_f)() << '\n';
}
```
### 出力結果
```plain
30

```
