# 関数ポインタとは
関数ポインタとは、関数へのポインタのことです。関数とは実態を持つオブジェクトなので、そのオブジェクトのアドレスを保持するポインタを経由して、関数を呼び出すことができます。簡単に言うなら、変数で関数を保持することができます。

ある関数ポインタが保持できる関数には制限があります。関数ポインタの宣言時に返り値と引数の型を宣言する必要があるので、その型に合った関数だけ保持できます。

# 関数ポインタの宣言
`返り値の型 (*変数名)(引数の型);`で宣言できます。この使用方法だと関数に別名を付けたように振舞います。関数からポインタを取得したい時は`&関数名`または`関数名`を使用します。後者は暗黙変換によって関数から関数ポインタに変換されます。
## 例
1+2を2回出力する。
### ソースコード
```cpp
#include <iostream>

int Add(int x, int y) {
    return x + y;
}

int main() {
    int (*f1)(int, int) = &Add;
    std::cout << f1(1, 2) << '\n';

    int (*f2)(int, int) = Add;
    std::cout << f2(1, 2) << '\n';
}
```
### 出力結果
```plain
3
3

```

# 関数ポインタの配列の宣言
`返り値の型 (*変数名[])(引数の型);`で宣言できます。同じ返り値と引数の型を持つ関数をまとめて扱えます。
## 例
1+2と1-2を出力する。
### ソースコード
```cpp
#include <iostream>

int Add(int x, int y) {
    return x + y;
}

int Sub(int x, int y) {
    return x - y;
}

int main() {
    int (*list_f[])(int, int) = {&Add, &Sub};
    for (int i = 0; i < 2; ++i) {
        std::cout << list_f[i](1, 2) << '\n';
    }
}
```
### 出力結果
```plain
3
-1

```
# 便利な関数ポインタ
関数ポインタはラムダ式を保持することもできます。また、`auto`キーワードを使用することで便利に関数ポインタを使用することができます。関数ポインタの配列は`auto`キーワードがうまく解決してくれないので、`std::vector<std::function<返り値の型(引数の型)>>`などを使ってみましょう。
## 例
1+2と1+2と1-2を出力する。
### ソースコード
```cpp
#include <iostream>
#include <vector>
#include <functional>

int main() {
    auto f = [](int x, int y){ return x + y; };
    std::cout << f(1, 2) << '\n';

    std::vector<std::function<int(int,int)>> f_list = {
        [](int x, int y){ return x + y; },
        [](int x, int y){ return x - y; }
    };
    std::cout << f_list[0](1, 2) << '\n';
    std::cout << f_list[1](1, 2) << '\n';
}
```
### 出力結果
```plain
3
3
-1

```
