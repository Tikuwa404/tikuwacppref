# `#define`マクロは使うな
これを読んでいるあなたはなぜ`#define`マクロを使用しようとしているのでしょうか。いくつか考えられる原因とその解決策を提示します。
-  コンパイル時定数を設定したい
  コンパイル時定数を設定するには、`constexpr`キーワードで修飾した変数が使用できます。`#define`マクロを使用するとグローバルに定数が設定されますが、`constexpr`キーワードで修飾した変数は変数なのでスコープがあります。適切なスコープに定数を置くことで、プログラムもすっきりするでしょう。
- 型名にエイリアスを付けたい
  型名にエイリアスを付けるには、`using`キーワードが使用できます。`#define`マクロを使用するとグローバルにエイリアスが設定されますが、`using`キーワードで付けたエイリアスはスコープ内でのみ有効です。また、エイリアスを設定しなくても、`auto`キーワードの型推論で複雑な型の変数を扱うことができます。
- いろんなところに出てくる同じ処理をまとめて書きたい
  同じ処理をまとめて書くには、関数や構造体、クラスが使用できます。様々なところでその処理が出てくるなら、関数や構造体、クラスがいいでしょう。ある関数内でだけ同じ処理を複数回使用する場合は、ラムダ式やローカル構造体、ローカルクラスを宣言しても構いません。プログラムを簡潔にするためには、ローカル構造体やローカルクラスの代わりに自分で設定した名前空間内に構造体やクラスをつくるのがいいかもしれませんね。

## 例
全ての整数に定数を加え出力する
### ソースコード
```cpp
#include <iostream>
#include <vector>

int main() {
    //エイリアスはusingで
    using seisuu = long long;
    //定数はconstexprで
    constexpr seisuu NUMBER = 3;

    std::vector<seisuu> v = { 1, 3, 5 };
    //長い型名はautoで宣言
    //ラムダ式で処理を共通化
    auto addNumber = [=](seisuu x){
        return x + NUMBER;
    };

    for (seisuu i : v) {
        std::cout << addNumber(i) << ' ';
    }
    std::cout << '\n';
}
```
### 出力結果
```plain
4 6 8 

```
# それでも`#define`が必要な場合
上記の方法では解決しない、`#define`でないと実現できないプログラミングでは、`#define`を使わざるを得ません。それでは、`#define`について見ていきましょう。

そもそもプリプロセッサディレクションとは、コンパイルの初期段階で働くプリプロセッサに指令を送る命令です。その中の`#define`マクロは**プログラム本文の中の**ある文字列を他の文字列に置き換えたい場合に使用します。プログラム本文を操作するという点でコンピュータに指令するためのプログラムの命令とは機能が異なることが分かります。

- `#define A`はプログラム中のAを削除するという働きです。
  Aが空文字列に置き換えられるように設定されている、と言い換えると分かりやすいかもしれません。
  Aに含まれるアルファベットは全て大文字にすることを推奨します。
- `#define A B`はプログラム中のAをBに置き換えるという働きです。
  Bにスペースが含まれていても大丈夫です。
  `B`の行末に`\`が来た場合、次の行も`B`の続きとなります。この時`B`に`\`は含まれません。
  Aに含まれるアルファベットは全て大文字にすることを推奨します。
- `#define A(X) B`はプログラム中の`A(X)`を`B`に置き換えるという働きです。
  この時、Bの中に含まれる`X`はプログラム中の`X`に置き換えられます。
  また、`B`の中に含まれる`#X`はプログラム中の`X`を`""`で囲ったものに置き換えられます。
  引数は増やすことができます（`#define A(X1, X2) B`）。
  `B`の先頭と末尾が`"`になっていると、文字列として認識されます。この場合はBの中に含まれる`X`はプログラム中のXに置き換えられません。
  
  `B`の行末に`\`が来た場合、次の行も`B`の続きとなります。この時`B`に`\`は含まれません。
  単語の中に`X`を埋め込みたい時、トークン連結演算子`##`が使用できます（`B`を`X1##_WITH_##X2`にするなど）。
  Aに含まれるアルファベットは全て大文字にすることを推奨します。
## 例
変数を変数名付きでデバッグ出力する
### ソースコード
```cpp
#include <iostream>
#include <vector>

#define DEBUG_LOG(X) std::cout << #X << ':' << (X) << '\n'
#define REP(I, N) for (int I = 0; I < N; ++I)

int main() {
    int variable = -1;
    DEBUG_LOG(variable);
    REP(temporary, 3)
        DEBUG_LOG(temporary);
}
```
### 出力結果
```plain
variable:-1
temporary:0
temporary:1
temporary:2

```
# `#ifdef`や`#ifndef`と組み合わせる
ライブラリを作る際に、デバッグビルドとリリースビルドでコンパイルするコードを変えたかったり、ファイルを1度だけコンパイラに読み込ませたかったりします。こういう場合は`#ifdef`を`#ifndef`を`#define`と組み合わせて使用できます。

`#ifdef`はプリプロセッサディレクションです。`#ifdef A`は、その時点で`A`が`#define`で指定された置換対象なら、次の`#else`または`#endif`までをコンパイルするように指示できます。もし`#define`で指定された置換対象でない場合、`#else`が存在するなら`#else`から`#endif`までをコンパイルするように指示できます。

`#ifndef`はプリプロセッサディレクションです。簡単に言うなら、`#ifdef`と反対の働きをします。`#ifndef A`は、その時点で`A`が`#define`で指定された置換対象でないなら、次の`#else`または`#endif`までをコンパイルするように指示できます。もし`#define`で指定された置換対象の場合、`#else`が存在するなら`#else`から`#endif`までをコンパイルするように指示できます。
## 例
変数を変数名付きでデバッグ出力する
### ソースコード
```cpp
#include <iostream>

#define DEBUGGING

int main() {
#ifdef DEBUGGING
    std::cout << "debug\n";
#else
    std::cout << "release\n";
#endif
}
```
### 出力結果
```plain
debug

```
