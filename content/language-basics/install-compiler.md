# コンパイラのインストール
WindowsへのC++コンパイラ（GCC）のインストール方法を説明します。

# 目次
- 
# なぜインストールがめんどくさいのか
C++のコンパイラにはGCC・clang・Visual C++などがありますが、筆者はGCCしか使ったことがないのでGCCの説明をします。
OSにはWindows・Linux・Macなどがありますが、筆者はWindowsがメインの環境なのでWindowsで説明をします。

GCCとは、「GNU Compiler Collection」の略です。その名の通り様々な言語のコンパイラが含まれていますが、その中のC++用コンパイラを使用します。

**しかし、公式にはC++で書かれたソースコードしか配布されていません。**
