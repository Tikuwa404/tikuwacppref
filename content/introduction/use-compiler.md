# コンパイラの基本の使い方
C++コンパイラの実行ファイルは「g++.exe」です。「main.cpp」を用意し、コマンドプロンプトで次のように入力します。

## 例
「Hello, World!」を出力する。
### ソースコード（main.cpp）
```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, World!\n";
}
```
### コマンドプロンプト
```batch
g++ -o main.exe main.cpp
main
```
### 出力結果
```plain
Hello, World!

```

# 便利なコマンドライン引数
`-std=gnu++XX`（XXにはバージョンを示す数字が入る）
コンパイラの初期設定が古いバージョンのC++を使用する設定になっていることが多いため、この引数で最新のC++を使用するように指示する。

`-O2`・`-O3`
指定すると最適化を行ってくれる。最適化が行われると、実行速度が上がったり、実行ファイルのサイズが変化する。`-O3`の方がより強い最適化を行うが、実行速度が上がるとは限らない。

`-mtune=native`
使用しているCPUに合わせて最適化を行ってくれる。古いCPUでも動くような互換性がある程度保たれる。

`-march=native`
使用しているCPUに合わせて最適化を行ってくれる。古いCPUでも動くような互換性が保たれない。
