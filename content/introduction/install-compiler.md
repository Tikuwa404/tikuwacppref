# コンパイラとは
プログラムはプログラミング言語で書かれます。しかし、このプログラムは人間に理解しやすい形式になっており、コンピュータは理解することができません。そこでコンパイラは、プログラムを機械語（コンピュータが理解できる形式）に変換してくれます。ファイルの拡張子に注目してみましょう。
- 「.c」・「.h」・「.cpp」などはソースファイルと呼ばれ、プログラミング言語で書かれる
- 「.exe」などはオブジェクトファイルと呼ばれ、機械語で書かれる

# なぜインストールがめんどくさいのか
C++のコンパイラにはGCC・clang・Visual C++などがありますが、筆者はGCCしか使ったことがないのでGCCの説明をします。OSにはWindows・Linux・Macなどがありますが、筆者はWindowsがメインの環境なのでWindowsで説明をします。

GCCとは、「GNU Compiler Collection」の略です。その名の通り様々な言語のコンパイラが含まれていますが、その中のC++用コンパイラを使用します。

**しかし、公式にはC++で書かれたソースコードしか配布されていません。**

おかしいですね。C++のコンパイラを入手するのにC++のコンパイラが必要になってしまいました。実は、新しいバージョンのC++コンパイラは古いバージョンのC++コンパイラで実行ファイルを生成するんです。では、私たちはどのようにGCCをインストールするのでしょうか。

答えは簡単です。他の人がすでにコンパイルした完成したコンパイラをダウンロードしましょう。そこで使うのがmingw-w64です。

mingwとは、「Minimalist GNU for Windows」の略です。このmingwの中のC++コンパイラを使うわけですね。
